# EXP-009/v1 Worker final report — FM4 versus AF4 continuation

2026-10-11 HKT. **The frozen experiment has finished; no further EXP-009 inference or training is proposed.** This is a Worker result pending Judge's final acceptance. The [taskbook](taskbook_v1.md), [C2 release](GPU_RELEASE.md), [C3 release](C3_GPU_AUTHORIZATION.json), [configuration](config.json), [frozen sources](source_manifest.json) and [CPU preflight](cpu_preflight.json) establish the permitted protocol. The checkpoint was AF2 **step32 only**; the failed EXP-008 DMD weights were not loaded.

Both candidates started from the exact EXP-006 FM8 12-latent/39-RGB C1 endpoint and identical A/D parking-lot seed13 inputs. Each built its own C1 clean raw KV. C2 used that common clean latent history; C3 used each candidate's own generated C2 latent and KV. FM4 loaded Original H3 + released action LoRA and used native scheduler steps, with no AnyFlow QKV or target-time module. AF4 added the frozen step32 rank8 QKV and target-time module and used four next-sigma finite maps. The native shift2.22 grid and Single I0/current-prefix/Global RoPE/strict causal settings were held fixed. This is a **4-NFE continuation** comparison, not full-video 4-NFE generation or a single-variable training-objective ablation.

GPU0 ran the two candidates sequentially, each `prefill → AA C2 → AD C2 → AA C3 → AD C3`, with full C2 review before C3. Each stage used `OMP_NUM_THREADS=4 MKL_NUM_THREADS=4 .venvs/h3world/bin/python -u submission/experiments/EXP-009_v3_fm4_af4/run_fm4_af4.py --model MODEL --stage STAGE [--path AA|AD] --gpu 0` from project root; exact stdout copies are in [logs](artifacts/logs). There were no retries, updates or backward passes. The [final budget copy](artifacts/raw/budget_final.json) records **38 forwards = 32 sampling + 6 clean commits, 8 VAE decodes, 782.290 GPU seconds = 0.217303 GPU-hours**. The earlier `budget.json` copy is the frozen C2 checkpoint. The highest allocated VRAM was **26.336 GiB**; C1 and C2 raw KV occupied **6.332 and 8.971 GiB** of CPU memory. These figures are within the 38-forward/8-VAE/0.60-GPU-hour/44-GiB approved limits. The 4-step sampling portion took roughly 22.5–22.7 seconds per C2 and 24.6–24.9 seconds per C3; weight load and VAE decode are additional, so no end-to-end speedup claim is made.

Horizontal flow is a camera/content motion proxy, not a formal action-accuracy score. Nevertheless the paired videos and full 17-frame contact sheets support a **limited FM4 AA/AD local direction response**, with visual quality **PARTIAL**. AF4's AD third chunk is a **generation-quality failure** in this bounded test: the parking lot remains visible but the person disintegrates and action response nearly disappears. AF4 AA also degrades badly. This does not prove all AnyFlow methods fail; it shows that this short-trained step32 student does not jointly beat the ordinary FM4 baseline at 4 NFE on this state. Existing FM8/AF8 references have better local structure but different sampling maps; no isolated objective-function effect or fair whole-video acceleration follows from these clips.

The Worker recommendation is to stop this AF2 step32 4-NFE line without 2-NFE or training extension. The bounded ordinary FM4 outcome is useful as a low-step reference, but its ghosting and the shared FM8 C1 prevent claims of a stable long-horizon four-step model. Further research should be a separately scoped task.

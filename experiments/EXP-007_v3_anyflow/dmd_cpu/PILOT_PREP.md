# Real-H3 DMD pilot entrance — preparation, 0 GPU calls

The [runner](run_pilot.py) and [configuration](config_pilot_prep.json) implement the one-cycle design in [GPU_PILOT_DRAFT.md](GPU_PILOT_DRAFT.md). This is **not an authorized GPU experiment**. CPU `--preflight` currently returns `WAITING_FOR_AF2_AND_AF3` because the final AF2 checkpoint and matched AF3 video are not yet complete. A separate Judge `DMD_GPU_AUTHORIZATION.json` with `approved: true` and the exact AF2 step is required before the runner will reserve any GPU. The first CPU-only protocol evidence remains [check_protocol.py](check_protocol.py) / [result.json](result.json).

The prepared execution uses three independently loaded H3 roles on three devices: frozen causal teacher, ordinary-FM fake score with fresh rank8 QKV, and the trained target-time student. Each role clean-prefills C1 with its **own** weights and CPU raw KV. C2 initial training noise uses a separate CPU generator seed 170008; score noise uses seed 170108. This prevents reusing the frozen seed13 evaluation noise. The student keeps the entire 8-map computational graph until the DMD backward. Fake consumes only detached endpoints, does two FM updates and rebuilds its own C1 KV after each. Teacher/fake score the same detached re-noised endpoint at sigma 0.6. The DMD score direction follows the frozen noise-minus-clean convention in `causal/dmd.py`.

The ledger reserves each of 17 forwards, 3 backwards, and 3 optimizer updates before execution, with 0 VAE calls. It records three physical GPU IDs, initial CPU/CUDA RNG hashes, the actual imported DMD module path/SHA, peak allocated memory by role, 30-minute wall cap and conservative `3 × wall` GPU-hours against a 1.5 GPU-hour ceiling. Both optimizers clip gradients to norm 1; fake and student caches, gradients and parameter changes are checked separately. This proposed ceiling is only a draft until Judge writes a formal taskbook. Checkpoints save only role adapters, optimizers and RNG, not base H3 weights or raw KV. Any failure remains in the ledger; no automatic retry.

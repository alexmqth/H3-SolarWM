The inference preparation then moves only ignored LoRA parameters to the local device and invokes the existing `wrap_h3_fsdp(..., frozen_base_shard_size=8)`. Released EMA weights are still restored by the unchanged post-wrap LoRA-only `load_initial_weights()`. Base revision and source hashes are in [SOURCE_RECEIPT.json](SOURCE_RECEIPT.json).

Eight simultaneous replicas thus need at least 524.75 GiB before Python, checkpoint and FSDP transient allocations. Observed MemAvailable was 546.53 GiB, only 21.78 GiB above that lower bound, while GPUs 2–5 were in use. This is **not** enough evidence to run the load test now. The [load-only proposal](GPU_LOAD_ONLY_PROPOSAL.md) requires a new authorization, all eight cards idle and a conservative 650 GiB free-memory gate.

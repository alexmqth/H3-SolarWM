## 异常和计量限定

1. V0 GPU 推理成功；CPU 展示导出后的帧率字符串断言导致最初外层 wall 未保存。该行 wall 由 launch 时间至原始 MP4 mtime 重建，为近似值、截止到文件保存，不含进程退出。没有因此重跑 GPU。原生生成阶段精确计时仍存在，不能将重建值冒充精确 perf_counter 数据。
2. V2b 首次新入口在文本编码时缺少 no_grad，OOM，0 denoiser forward，完整失败 wall 17.472283s、allocated 峰 43.634626 GiB。失败目录保留，补齐推理上下文后一次重试成功；没有降低精度、改 sampling steps 或换输入。失败记录中 reserved=0 是未采集字段的默认值，不是实际零占用。失败成本计入实验总预算，失败峰不混入成功行的正常成本。
3. 本轮 n=1，顺序运行没有清空系统缓存。V0 首次加载/条件编码明显更慢，故完整 wall 比值不能视为消除系统因素的算法 speedup。Legacy 与 native 的子项计时边界不同，完整 wall 包含实际加载、编码、采样、提交、模型切换、解码、保存；子项只用于解释，不能直接混加。
4. 保留版本实际差异：V0 原始联合 audio/video 去噪；V1 latent dual anchor；V2a RGB anchor/adapters；V2b 历史重算；V3/V4 persistent raw KV/current prefix。Legacy 与 native h3_fp32 边界策略、attention 调用路径也有区别。这是方案级对比，不是单变量 KV 消融。
5. GPU 主列是 PyTorch allocated 峰，不是 NVML 峰或模型所有权重总量。统一 offload 后各行 GPU 峰相近，不能宣称已测得明显 GPU 显存节省；CPU KV 应一并考虑。原始/展示视频时长和成本范围不同但已显式标注。

## 预算与验收决定

完成行累计 **645 次 denoiser forward**：614 次 sampling + 31 次 commit；prefill=0、训练=0。完成行 wall 6399.645648s；加唯一失败 17.472283s，共 **6417.117931s = 1.782533 单卡墙钟 GPU 小时**。未超过 850 forward / 4 GPUh / 每行 2700s 的任务预算。V0 重建时间的近似限定保留，总预算使用单卡占用墙钟口径而非纯 kernel 执行时间。

**接受任务交付，停止本轮 GPU 工作。** V3 Baseline 正式定位保持；V3 FM-8NFE 是当前更值得优先使用的因果原型工作配置，但质量与连续性仍 PARTIAL。V3-30NFE 相较 V2b 的整片观测成本降低约 37.5%，相较 V0 本次完整 wall 更长；FM-8NFE 相较同路线 30NFE 的完整 wall 降低约 62.8%。不将 V1 的低成本或 V4 的较短运行时间解释成有效能力收益。

当前 DMD cycle8 方向保留完整负结果，不新增训练、checkpoint 筛选或采样消融。下一项研究的高收益候选仍是已有固定动作布局的真实模型回归与真实混合动作条件验证，见 EXP-017 后续草案；本次验收不构成新 GPU 任务授权。

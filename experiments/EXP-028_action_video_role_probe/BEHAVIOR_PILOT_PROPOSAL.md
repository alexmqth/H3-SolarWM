# One behavioral follow-up candidate (proposal only; 0 new GPU calls)

The rank-8 role gradients do not show a clear new action/video conflict unique to V3. The next useful question is whether the single **non-action prefix → current video** feedback edge has a measurable *behavioral* effect in a short C2 action intervention. This is more direct than training dual adapters from the gradient cosine result.

## Fixed comparison

Use the two ABot initial states already encoded in EXP-023. For each, commit the **same** GT C1 (12 latents) once with the frozen V3 public-prefix feedback topology, then fork the same detached raw KV, I0, C2 initial noise and 30-step schedule into four 5-latent C2 continuations: A and D under (1) current V3 topology and (2) only the non-action prefix feedback edge removed. Reusing one identical C1 KV is necessary to isolate the *current C2* edge; recomputing C1 separately under both topologies would also change history. This is a short 17-RGB-frame C2 test, not a 124-frame generated-history result.

The code path is already visible: [current_prefix.py](../../reports/stage1_anyflow/02_causal_diagnostics/current_prefix_candidate/current_prefix.py) adds one line, `prefix_feedback_mask[ann < 0, current_video_offset:] = True`, to `ChunkAttention.attend` and verifies by AST that this is the only source-level difference. The control uses `action_prefix_mode='own'` and `action_feedback=True`. The off condition should use the unpatched `ChunkAttention.attend` with the same mask, cache, sigma, global RoPE and current action rows. Before any GPU run, a CPU mask check must verify that action rows still read only their own V_k, while non-action prefix reads current video only in the on condition. Future rows must remain physically absent.

The two existing `condition.pt` files provide source RGB-derived I0, factual C1/C2 latents, audio noise, native packed layout and prompt embeddings; their records and SHA are already frozen in [CPU_PREFLIGHT.json](CPU_PREFLIGHT.json). They **do not** contain a matched D counterfactual prompt: the first clip is constant “backward + left, camera pans right,” and the second is mainly left followed by still/forward. Creating matched A/D current-action rows therefore needs a separately audited fixed-layout tokenizer/text-encoder step, likely through the EXP-017 layout builder. Do not relabel factual prompt rows or splice embeddings across incompatible token positions. Preserve the same historical action rows and vary only C2 action rows; verify packed lengths, action–video index alignment and Global RoPE before generation.

For assessment, show A vs D within each topology and on vs off within each action. Inspect person motion and background/camera motion separately, plus body structure and chunk boundary. Global horizontal optical flow alone can mix character and camera effects. A behavior difference would motivate a controlled action/visual trade-off study; no difference would argue against prioritizing this single edge. Either outcome remains a local two-state result. No training, AnyFlow or DMD follows automatically.

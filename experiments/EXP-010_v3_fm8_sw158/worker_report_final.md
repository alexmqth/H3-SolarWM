# EXP-010/v1 Worker final report — full FM8 + SW-G to 158 frames

2026-10-11 HKT. **All separately authorized EXP-010 GPU stages have finished; no further chunks, parameter changes or training were run.** [Judge's independent final review](judge/FINAL_REVIEW.md) accepted bounded 158-frame feasibility with quality PARTIAL and a weak first D-switch chunk. This Worker report preserves the execution details separately. The experiment combines the already generated EXP-006 ordinary FM8 AA73 history with the certified EXP-005 Global RoPE/five-ancestor window. It asks whether eight-step causal continuation keeps a visible person/scene and reacts to a late A→D switch after real KV eviction.

The actual chain was: EXP-006 FM8 first12 + AA C2/C3 endpoints and its own C1/C2 raw KV → clean C3 commit → ordinary FM8 C4/C5/C6 to AA124 → common AA124 fork → C7/C8 A-continue and D-switch to 158 RGB frames. Each new block used the frozen native shift2.22 eight-step H3 scheduler, Original H3 + released action LoRA, Single I0, own-action/current-prefix feedback, Global RoPE and strict chunk-causal attention. There was **no AnyFlow or DMD module and no new training**. The long47 fixture preserved old 0:37 conditions and appended seed130005 noise for 37:47; it is the certified explicit extension, not the default full-length H3 builder. C7/C8 branches share the same 124 RGB/raw history and differ in action spans from latent 37 onward. The provenance is bound by the [36-source manifest](source_manifest.json), [taskbook](taskbook_v1.md), [core release](GPU_RELEASE_CORE.md) and [branch release](CORE_REVIEW_AND_BRANCH_RELEASE.md).

GPU0 ran eight sequential calls under one locked ledger: `commit_c3`, `C4`, `C5`, `C6`, `C7 A`, `C7 D`, `C8 A`, `C8 D`. Full stdout and per-stage JSON are archived under [core](artifacts/core) and [branch](artifacts/branch); large endpoints and CPU KV remain under `H3-World/outputs/EXP-010_v3_fm8_sw158/`. There were no failures or retries. The [final ledger](artifacts/branch/budget_final.json) records **62 forwards = 56 sampling + 6 clean commits, 7 VAE decodes, 0 updates, 1137.109 GPU seconds = 0.315864 GPU-hours**, within the 62/7/0.75 GPU-hour cap. Peak allocated VRAM was about **26.596 GiB**. Once eviction begins, the retained raw video KV is 14,164,800,000 CPU bytes (13.19 GiB), with exact five ancestors in all 50 layers. Prefix, saved latents/RGB and full-prefix VAE decode are not bounded by that KV figure; repeated model loading/cache I/O are included in the GPU-time ledger, so the result is not a fair whole-video speedup estimate against existing 30-step clips.

# V4：SGF / DMD研究路线

SGF = Self-Gradient Forcing（自梯度强制）；DMD = Distribution Matching Distillation（分布匹配蒸馏）。目的：让少步学生在自身生成样本上接受分布匹配训练，改善推理分布下的生成质量。

V4是用户指定的研究分类，**当前无已验收生成模型**。EXP-008三角色与完整8-map梯度工程通过，但最终AA C2新增17帧全彩噪，生成FAIL、当前配置归档。旧Stage2-lite另列，条件/权重不同。

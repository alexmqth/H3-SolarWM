# V3 原权重 8 步续写：EXP-004

2026-10-10。普通 native FM/Euler 从每个新块 30 步减到 8 步，原权重、strict chunk-causal 和 persistent raw KV 不变，零新增训练。单停车场 seed13，AA/AD 都续到 73 帧（24fps，3.04秒）。Judge 接受有限可行性，画质/严格连续性 PARTIAL。

同history第二块保留可辨的A/D运动差异，第三块在自己的8步历史下仍有基本人物/场景结构。flow仅作辅助代理。AA后段透明肢体/腿部拖影较明显，另有软化、背景纹理重叠、边界姿态跳变；AD有局部腿部纹理/残影。没有持续整体人物崩坏，但尚不能称成熟画质。

本轮32sampling+2commit=34forward，4VAE，0训练/首窗prefill/额外模型诊断。GPU0顺序执行，466.018 GPU秒（0.129449 GPU小时），GPU运行区间约9.56分钟，峰值allocated25,682.07MiB。sampling内含历史cache读取/搬运，未拆分计时。30步参考来自旧实验，不同时刻共享硬件；上述是单次观察成本，不能作为公平E2E速度比。借用首窗的成本不包含在本轮内。

## 决策与范围

这组证据说明原权重有直接减步余量，暂不需要靠训练才能获得少步正信号。正式30步V3的124帧证据继续保留；本轮只验证8步续写到73帧。下一项高ROI问题是从首窗也使用8步，并在自身历史下延伸，检验能否解除对30步前缀的依赖；先做有限任务，再决定是否值得少步适配。当前EXP-004已结束，不自动扩展训练、参数扫描或124帧推理。
